# 训练、评估与研究产物

本目录保留模型训练结果、候选模型、数据集、评估报告和历史研究资料。自动生成的新产物已由 `.gitignore` 排除；已经纳入 Git 的历史资料仍受版本控制。

配置和代码可能引用本目录中的文件，例如：

- `screw-adaptation-v4-2026-10-17/training-result.json`：由螺丝检测配置引用。
- `sticker-inspection-2026-10-17/action-training-result.json`：由贴条检测配置引用。
- 各训练目录中的权重：可供后台模型导入和实验复现使用。

整理时上述两个训练结果 JSON 已缺失，未删除或伪造补齐；模型权重和参考图仍在。螺丝 API 对缺失训练元数据返回空值，该元数据不影响权重文件的读取。

`screw-action-training/` 从原根目录 `screw_action_training/` 归入这里，保留数据、权重、运行报告及仅剩的编译代码。数据集 YAML 的根路径已更新；完成训练的历史日志保留原始路径作为来源记录。

浏览器测试产物另存于 `test-results/`；文献调研及单工位方案已移至 `docs/research/`。删除训练产物前应核对配置、模型库和实验引用，不能整目录按缓存处理。
