# 服务器离线分析首版：开发与验收记录

日期：2026年10月2日。基于现有D:/Project/myarc开发，优先实现上传分析基本链路，未实施研究文档中的全部生产架构。

## 已完成

1. FastAPI服务：登录、退出、Cookie会话、CSRF校验、流式视频上传、媒体校验、异步任务创建／查询／取消、任务历史和授权产物读取。
2. SQLAlchemy持久化：媒体、会话、任务、幂等键和schema版本。生产配置要求PostgreSQL，测试及本机开发允许显式SQLite。
3. 独立Worker：串行领取任务、后台续租、过期恢复、最多3次尝试、递增token、旧Worker拒绝发布、模型与源文件哈希校验。
4. 算法模块：视频校验、原姿态规则与跟踪基线、时序片段聚合、最多6张证据图、WebM预览、JSON／CSV／HTML报告和哈希清单。
5. 现有Web接入：服务器登录、上传状态、任务轮询、刷新恢复、历史任务、结果回放及下载；取消按钮只在可取消状态显示。
6. 修复：CSV模型型号写死、全视频原图缓存、无效元数据除零风险、未来采样提前显示、切换场景的迟到请求、静态资源路径越界访问。
7. Linux GPU部署文件：API与Worker Dockerfile、PostgreSQL、初始化任务、Nginx HTTPS、持久卷和服务健康依赖；补充运行及恢复说明。

## 真实推理记录

本次浏览器验收从已有factory-workers.mp4生成约1.33秒、640×360短片。运行ID：`fa1d7f97-3e1d-484e-aca5-6f8b1fc29c1b`。

- 模型：YOLO11s-pose，输入尺寸640，5 fps采样。
- 设备：NVIDIA GeForce RTX 5070 Ti，PyTorch 2.8.0+cu128。
- 7个采样帧，最多5人，5条轨迹段，7个姿态片段。
- 模型推理均值约8.49 ms，P95约11.48 ms；这是短片运行记录，不是吞吐量或生产精度验收。
- 浏览器未捕获页面脚本错误；SOP结果为REVIEW，合格率与违规数没有伪造确定值。
