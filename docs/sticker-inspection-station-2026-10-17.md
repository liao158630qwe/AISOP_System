# 螺丝与贴条独立任务：工位使用与部署准备

界面保留原深色布局，在“检测任务”选择“螺丝安装检测”或“贴条工序检测”。两类任务使用各自模型、标定、历史记录和实时轮次，切换任务清空当前视频、观察与结论。刷新保持空工作区，仅记住任务选择，不自动打开历史视频。

工位可分别收藏 `http://127.0.0.1:8000/?task=screw`、`http://127.0.0.1:8000/?task=sticker`。URL只选择任务，不开启摄像头或恢复视频。当前服务运行在本机，尚未连接工位PLC或部署到现场。

## 贴条规则

正确素材为 `C:/Users/Administrator/Downloads/lv_0_20261017162449.mp4`。此前的161554视频是用户更正前的错误素材，未用于贴条训练。

人工核对的贴合位为两个三角、六个方形（含长方形）位置。两个三角都应先完成，随后才贴方形；两个三角之间及六个方形之间不强制额外顺序。按用户要求，系统只核对对应位置是否出现贴放/按压动作，不依赖黑色贴片与黑色零部件的外观差异。每处需要先有无动作基线，再观察到接触候选和随后的离开；多帧运动接触或单帧高置信接触均可确认，未定位、遮挡和静止成品不计完成。没有按照视频秒数编排检测结果。

八处动作记录齐全且两处三角动作早于所有方形动作才判动作合规；结束时缺少任一位置动作或观察到错序判不合规；从成品开始、遮挡或没有取得动作证据时判动作证据不足。定位模板需与工件对齐，模板取走、相对移动和关键定位区域不可核对时保留未知。检测框只绘制当前有效采样的动作候选，不复用历史框。工序计数是已观察到的历史事件，与当前画面动作候选分开显示。

当前范围为标定位置的贴放/按压动作与操作先后证据；不核验贴片实际存在、形状、外观、粘附强度，也未验收工厂要求的毫米级贴合偏移。相似扶持、手部经过或短暂停留仍可能被误计，现场投用前需用不同人员及真实漏动作、错序样本验证。

当前正确视频的完整回放和实时接口均取得8/8动作确认，两处三角动作早于第一处方形动作；成品静置和空白画面不产生动作，先方形后三角的回放判为动作不合规。实时接口按1080×1920 JPEG94、4FPS连续提交核对。上述是同源开发验证，不是独立工位准确率。完整记录见 `outputs/sticker-inspection-2026-10-17/action-report.md`。

## 每件工件的操作

1. 选择本工位任务和摄像头，点击“开始实时检测”；从贴之前开始采集。
2. 当前任务保持一个轮次。贴条面板显示两个三角和方形的已确认动作数量、当前动作候选与顺序证据。
3. 工序结束点击“结束并判定”，查看合规、不合规或无法判定及其原因。
4. 下一件工件开始新轮次，不将上一件的过程证据用于下一件。

贴条实时采集优先请求竖屏 1080×1920，并以 JPEG94 提交；螺丝任务仍优先横屏 1920×1080。摄像头实际分辨率、方向和镜头视角需与标定模板一致，否则会保留未定位而不是猜测动作。

本地浏览器访问localhost可以调用摄像头；跨机器浏览器采集应使用受信任的HTTPS站点。部署服务器、认证与反向代理参考 `docs/server-quickstart.md`，不要把开发启动方式直接作为现场验收。

## 独立资产与接口

螺丝使用 `config/screw-inspection.json`，贴条使用 `config/sticker-inspection.json`。贴条当前为动作模式，模型为 `models/sticker-actions-v1.joblib`，按精度优先保留 CPU 推理；螺丝检测使用 CUDA GPU。动作候选配置和启用前核对记录分别保存在 `config/sticker-action-candidate.json`、`outputs/sticker-inspection-2026-10-17/action-promotion.json`；旧外观候选保留用于历史对照。权重和参考图位于 `models/`，每个任务快照记录配置、模型及参考图哈希；修改后新建检测任务，历史结果不会自动变成新模型结果。

- `GET /api/v1/inspection-tasks`：可选任务及就绪状态。
- `GET /api/v1/screw-model`、`GET /api/v1/sticker-model`：各自模型与规则。
- 上传文件后，创建任务时明确 `options.analysis_type` 为 `screw` 或 `sticker`。
- 实时 JPEG 请求明确 `/api/v1/realtime/frame?analysis_type=sticker`，使用每件唯一UUID的 `X-Stream-Id` 与递增采样时间。
- 结束贴条轮次必须用 `/api/v1/realtime/streams/{UUID}/finish?analysis_type=sticker`；旧螺丝结束接口的默认值仍为screw，避免混用。
- 检测记录用 `analysis_type` 筛选，两种任务互不读取检测结果。

现场机位、定位模板、光照或零件变化时应重新标定并独立验证。当前动作模型来自一个正确过程视频的开发训练，裁剪训练/测试及整段复测不能当成独立工位准确率；现场投用还需要真实漏动作、错序、遮挡以及不同人员、手套颜色和动作习惯的样本。
