# 检测按键与 Modbus 声光设备设置

主界面顶部的「设置」在新页面打开 `/settings`，其中「检测触发」管理按键开关、键位与使用说明。主界面不显示按键配置面板，快捷触发仍然生效。默认开启，默认键为 **F8**。普通键盘和能发送键盘按键的 USB 按钮 / 脚踏开关共用此入口。现场设备需配置为发送单个按键的按下 / 松开事件。

## 操作

1. 登录，选择检测任务。模型任务确认模型就绪；工位1–6在工件登记停用时，准备图像并配置检测模型即可；启用人工登记的工位沿用工件检查流程。
2. 按 F8 开始当前任务。模型任务开始新的实时摄像头检测；人工工位建立当前工件周期。
3. 如设备发送其他键，进入「设置」→「检测触发」，点击「设置按键」，按键或踩一次脚踏，返回检测工作台后即可使用。设置页面仅录入和保存按键，不启动检测。Esc 取消录入。支持单个功能键、字母、数字、空格和 Enter；录入时排除 F1/F5/F9/F11/F12，不接受组合键。F9 固定为停止键，旧的 F9 开始键配置会按 F8 读取。
4. 在设置页关闭「启用按键触发」可停用快捷触发，原有按钮继续可用。开关与键位保存在本机当前浏览器的 localStorage；刷新后保留，同源其他页面同步设置。

保持检测页面在前台。输入框、扫码输入、下拉框和可编辑文字区域内，仅功能键会触发；空格、Enter、字母和数字保留输入含义。推荐配置为 F8，以便扫描工件编号后直接按开始。弹窗打开时不触发开始键，F9 仍可停止当前检测。

开始键只开始检测。检测中、上传中、切换任务中、结束处理中以及工位断线、存储不可用、图像未就绪时均不启动；不排队补触发，不切换成停止操作。每次按下须先松开才能再次触发，并有 600ms 防抖及启动期间的互斥保护。鼠标与按键共用业务启动函数。

F9 使用独立的停止入口：自动检测工位执行「停止本轮」并释放摄像头，不自动判定通过；普通实时模型任务沿用结束并判定，离线分析沿用取消任务。长按、重复停止与正在结束时的重入会被拦截。人工登记流程仍使用原有确认/关闭入口。

摄像头人工工位在上一件保存结束、关闭确认弹窗后，可直接再次按开始键建立下一件。沿用产品型号和摄像头，清除旧工件编号，由服务器生成新的本站临时编号。需要绑定实际条码时，先选「下一件」，扫码后再触发；返工按原有返工入口关联原周期。图片/回放联调必须先选「下一件」并换入新素材，以免重复使用上件图像。

## Modbus 按键与三色报警灯草稿

设置页第二部分支持工位1–6独立准备连接、按键输入、灯光输出和联动规则。当前 I/O 模块与点位尚未确定，因此只实现本机浏览器配置草稿与灯态预览，尚未连接、轮询或写入 Modbus 设备。

- 连接：模块/PLC 型号、TCP 或 RTU、设备站号、主机/端口或串口参数；未知字段可以留空。
- 按键：开始、停止两个输入，分别配置点位类型、协议地址、可选寄存器位号与有效电平。
- 声光设备：按用户提供的信息预填「正泰 ZTP-NP、24V」，红/黄/绿灯与蜂鸣器分别配置。供电类型、完整型号、接线、Modbus 接口和蜂鸣器是否可独立控制尚未核实。
- 规则：默认待检测/停止黄灯常亮、检测中黄灯闪烁、合格绿灯常亮、不合格红灯闪烁并启用蜂鸣器、待复核黄灯闪烁；这些是可修改的草稿规则，并非已验证的现场动作。
- 预览：支持状态选择及「预览按下开始/停止」，只更新页面灯态，不运行检测、不发设备指令、不播放声音。

有效修改自动保存到 `aisop-modbus-drafts-v1`，按六工位隔离，同源设置页同步。表单检查地址范围、位号范围和重叠点位；地址 `0` 有效，整字与同地址的位映射不能重叠。「导出六工位配置草稿」输出 JSON，标明 `status: draft` 与 `hardwareVerified: false`；导出不代表设备已接入。配置不上传服务器，也不被运行中的检测任务读取。

接入实物前需补齐 I/O 模块/PLC 型号、通信参数、输入/输出点位表、灯具完整规格与接线方式，并确定断线与掉电时的灯态。

页面公共入口为 `InspectionTrigger.requestStart(source)`，经页面开关、弹窗、前后台、启动互斥、防抖及当前任务的业务就绪检查后调用同一启动函数，返回 `{accepted, reason?}`。它只代表本次启动请求是否被接受，实际检测状态仍以业务控制器为准，不代表检测成功或产品通过。

停止入口为 `InspectionTrigger.requestStop(source)`。这些入口目前由键盘使用，配置草稿与灯态预览不会调用它们。后续硬件适配应将按键输入与实际检测结果的声光输出分别接入。

后续在服务器或本机设备网关加入 Modbus 适配层，再将新产生的按钮上升沿通知指定工位页面，调用该入口。具体接入前需确定 TCP/RTU、连接地址、站号、线圈/寄存器地址及有效电平。适配层应执行边沿检测、防抖、事件唯一编号去重、工位绑定、断线提示，并丢弃重连前的历史事件；按钮持续有效时不能持续建立周期，检测期间的触发不能留到结束后补执行。需要后台独立运行的现场控制，须另行提供服务端周期接口，不能依赖浏览器前台快捷键。

## 验证

- `npm run test:trigger-ui`：真实页面代码、模拟 API 与摄像头；键位录入与持久化、F9 停止与六工位摄像头释放、输入和弹窗保护、长按/防抖/鼠标竞态、启动失败重试、任务切换，以及 Modbus 草稿隔离、校验、持久化、导出、灯态预览与窄屏布局。
- `npm run test:pilot-ui`：隔离数据库中的完整人工工位流程，包含 F8 开始、长按不重复建立周期、摄像头下一件及六工位流程回归。
- `npm run test:api`：包含新增静态资源发布检查。

测试中的浏览器键盘事件用于验证键盘模拟协议，不能替代实际 USB 按钮、脚踏或 Modbus 设备的现场联调。
