# 从视频到训练数据

入口：管理页或工业训练页的「视频训练数据」，地址 `/datasets`。

## 现场操作

1. 新建数据集，选择采集工位和训练类型，填写固定类别。当前支持矩形框目标检测、整图分类。动作步骤、动作时间段和 SOP 顺序不在此流程中。
2. 上传视频并如实填写产品、机位、生产批次、工件周期或连续采集段、光照、遮挡。先确定整段视频归入训练、验证或测试集合。同一个原视频、生产批次、工件周期不能拆到不同集合，禁止为了凑数量改写批次信息。
3. 设置抽帧上限，默认 60 张。后台均匀抽帧，跳过解码内容完全相同的帧。近似帧、片段覆盖和标签质量仍需人工检查。上传结束后可关闭页面，重新打开能看到进度。
4. 点击图片复核。检测任务选择类别后拖动画框，并标全画面中的目标；分类任务给整张图片选择一个类别。没有目标的检测图片要显式确认空背景。模糊、不可判定或无效图片可排除；未经复核的图片不能导出。
5. 按覆盖表补充独立视频。默认每个集合至少 3 个独立批次、每类 20 张图片；检测还需要每集合至少 20 张真实空背景/难负样本。页面允许调整，最低为 2 个批次、5 张每类图片、5 张负样本。这些是数据门槛，不代表足以达到生产准确率。
6. 点击「审核并生成训练版本」。后台检查来源、批次、周期、类别和重复内容隔离；通过后生成独立图片与标签副本。再点击「进入训练」，工位、类型、数据版本和门槛会自动带入。
7. 在训练页选择类型匹配的可信初始权重，设置训练参数并提交。通过独立测试的视觉模型以停用候选登记，现场验收和场景发布按原流程完成。

只有一段视频时，可以先完成上传、抽帧和标注；不能把同一视频切成三份冒充独立训练、验证、测试数据。需要继续收集不同批次的视频。检测模型训练也不会自动获得动作先后顺序能力。

## 失败、编辑与版本

- 上传网络中断时，保留原文件和采集配置重试。前端保留幂等请求编号，服务器按文件内容及配置核对，防止重复任务；刷新后可以先检查视频记录。
- 抽帧失败不会发布半成品。任务失去租约后会失败，可点「重试」。坏视频或采集信息填错时，等待任务结束后移除该视频并重新上传；移除会删除当前标注。
- 审核时暂时锁定当前数据集编辑；审核完成或失败后解锁。审核失败原因显示在版本列表。
- 标注带修订号，另一个窗口已经保存时会提示冲突。关闭标注窗口、刷新并重新打开后再编辑。
- 已成功生成的版本保存独立副本。修改标注、移除原视频不会改变旧训练版本。训练工作器再次核对审核摘要，阻止已导出内容被磁盘修改后悄悄进入训练。
- 当前每个数据集最多保存 20 个成功版本；继续迭代时新建数据集。成功版本不会被自动清理，部署时需按训练版本规划磁盘容量。

## 服务器部署与资源

- 沿用现有 API、Worker 和数据库。升级代码后先执行 `python -m backend.init_db` 创建新增表和索引，再重启 API 与 Worker。无需额外任务服务。
- API 与 Worker 必须共享同一个 `DATA_DIR`，包括 `video-datasets`；多主机部署需要真正共享存储。数据库中的路径为相对路径，冻结版本通过有归属校验的 `dataset://` 引用传入训练。
- API 流式接收原视频，每个 API 进程最多同时接收 2 个此类上传；最多等待 10 分钟。原视频默认 500 MiB、600 秒、4K/120 fps；每段最多抽 300 张。单数据集上限 100 段、3000 张抽帧预算、10 GiB 原始视频。
- Worker 旁路监督独立 CPU 子进程处理抽帧与数据审核，隐藏 CUDA，限制 OpenCV/数值库线程。数据库唯一槽位让多个 Worker 总共只运行一个此类数据任务；任务上限 30 分钟，30 秒租约，后台定期续租。GPU 模型训练继续使用原来的独立队列。
- 页面每页 24 张缩略图，原图仅在打开标注时读取；数据集列表每页 25 项。任务活跃时轮询 3 秒，空闲 15 秒，出错逐步退避至 60 秒，页面隐藏时暂停读取。
- 文件复制、抽帧和审计均在数据库写事务之外完成，最后凭任务令牌与有效租约原子发布结果。进程崩溃或租约过期不能发布旧结果。
- 后台分批扫描并清理超过 24 小时且没有数据库引用的上传残留、失败尝试和已移除视频文件。保留全部成功导出版本和仍被引用的抽帧。每 5 分钟最多检查 10 个数据集，较大安装的回收时间可能超过 24 小时。
- 开始上传、抽帧及复制版本前检查磁盘空间，要求保留至少 1 GiB。该检查不能替代主机磁盘监控；原视频、原图、缩略图、训练版本和训练快照都会占用空间。
- Nginx 已给视频上传路径配置 600 秒代理读写超时，并关闭请求缓冲。修改上传大小时需同步 API 的 `MAX_UPLOAD_BYTES` 与 Nginx 的 `client_max_body_size`。
- 新数据接口使用原会话、CSRF 和归属校验；图片也需登录。不会把视频或图片路径加入公开静态文件服务。

## 验证

`npm run test:datasets` 使用合成视频检查原始视频/批次隔离、幂等上传、完整抽帧、精确去重、复核冲突、分类与检测导出、版本冻结、失联恢复和子进程运行。

`npm run test:datasets-ui` 启动独立测试数据库、API 和 Worker，实际上传 6 段合成视频，操作画框和分类标注、生成训练版本、检查分页与移动端、退出清除页面，再以导出版本执行 1 轮 CUDA 检测训练。随机图片预期不能达到准入门槛，该测试只验证工程流程，不构成现场精度证据。

PostgreSQL 并发验证需要单独设置 `TEST_POSTGRES_URL`，使用专用测试数据库。未配置时测试跳过，不宣称完成服务器 PostgreSQL 验证。
