# 六工位人工检查流程

2026-11-05：入口为 `http://127.0.0.1:8000/` 的“检测任务”，提供工位1至工位6。也可直接访问 `/station-2` 至 `/station-6`，地址会转到同一主界面对应任务。

| 工位 | 检查项目 | 当前工序关系 |
| --- | --- | --- |
| 1 | H01–H04 定位孔、S01–S04 螺丝 | 先保存4孔证据，再检查4螺丝 |
| 2 | S01–S05 螺丝 | 5处逐项核对 |
| 3 | S01–S02 螺丝、黄色卡扣安装记录 | 两类项目独立取证，先后关系待确认 |
| 4 | S01–S02 螺丝 | 2处逐项核对 |
| 5 | 端子连接记录、S01–S08 螺丝 | 先保存端子记录，再检查8螺丝 |
| 6 | 壳体吹净、装饰框总成吹净、线束端子连接、S01–S04 螺丝 | 四类项目独立取证，先后/并行关系待确认 |

检查项依据用户提供的《灯具装配行为分析与工序时序合规系统优化方案》配置；文档中的采购、部署、模型训练和验收建议未作为本次实施指令。

本次是人工流程接入，沿用工位1的摄像头/本地图片/本地视频预览及截图取证能力，没有训练或接入新模型，没有增加视频自动分析。各检查项逐项勾选，保存阶段截图时填写确认内容及当前账户密码；全部项目完成后再结束保存。工位3、6可通过“选择检查项目”切换可独立进行的阶段，清单展示顺序不构成强制工序。

黄色卡扣和端子数量、具体位置及可见完成标准尚未确定，因此以人工记录项占位，不将一项记录解释为一个零件。工位6的吹净区域、持续时间以及各项先后关系也待现场确认。工位3、5、6完成全部人工记录后保存为“待复核”，不会显示未经确定的工艺通过。工位1、2、4完整人工确认后可保存为“人工参与通过”；算法结论均为“未运行模型”。

每个工位同一时刻仅有一个活动周期，六个工位可各自保留活动周期。切换工位停止当前采集、清除界面中的确认项；返回或刷新后恢复该工位服务端周期，核对同一工件后继续。历史搜索、分页和导出均对应当前工位，返工须在原工位重新建周期。已有工位1记录与冻结配置兼容，无需数据库迁移。

工位1/5有强制前置关系的视频取证时点须严格递增。无先后关系的项目可按任意顺序分别取证。结束前核验全部截图完整性，所有末端项目证据须在3分钟内；过期时点击“重新核对末端项目”，选择相应项目重新保存。完整操作、认证、异常及备份说明沿用[工位1人工流程](station-one-pilot.md)。

后续现场确认或视频/模型接入时，可在 `backend/pilot_config.py` 更新工位定义，并递增规则版本。周期创建时冻结配置，已有记录保持原工艺定义。公共目录为 `GET /api/v1/pilot/stations`；状态和历史接口增加 `station=station-2` 等参数，创建周期携带 `station`，省略时兼容工位1。
