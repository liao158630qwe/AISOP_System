# 可选择的算法测试工位

主页面“检测工位”选择“算法测试工位”，勾选举手、握拳／抓握候选、通用目标识别。使用上移按钮调整顺序；勾选“按所选顺序测试”时，每一步需要连续三个返回帧检出，超过一秒的采样间隔中断连续计数。取消顺序模式则独立显示各算法输出。重新开始会清空本次测试进度，不保存为生产SOP或产品质量记录；跨帧不保证同一个人，测试完成不等于生产合格。

在视频分析栏选择实时摄像头并开始。默认显示带人体框、骨架、目标框和手部连线的检测画面。“原始预览”不叠加标注。桌面画面高度300px，手机220px，采用等比缩放，不截断图像。右侧显示测试步骤，画面下显示帧率与结果摘要。修改勾选项或顺序后重新开始生效。

| 测试 | 实际算法 | 含义与限制 |
|---|---|---|
| 举手 | YOLO11s-pose肩/腕关键点，分数≥0.5且腕点高于肩点0.04画面高度 | 左右手分别检测；不使用互斥姿态标签替代举手判断 |
| 握拳／抓握候选 | MediaPipe Hand Landmarker 21点，食指至小指关节夹角；至少三指弯曲为候选 | 使用世界坐标角度减少画面旋转影响；不确认握持力度、手物接触、抓牢或工序完成 |
| 通用目标 | YOLO11n COCO预训练检测，阈值0.4 | 包括人、杯子、瓶子、手机等通用类别；不具备灯具螺丝/卡扣等专用检测能力 |

黄线为手部骨架，紫框为通用目标，绿框和骨架为人体姿态。无检出显示“未观察到”，不会虚构动作；缺失模型明确显示“模型未就绪”。所有模型在服务器执行，首次加载较慢，同时启用多个模型的检测速率会低于仅运行人体姿态。

资源：`models/yolo11n.pt`来自Ultralytics官方发布`https://github.com/ultralytics/assets/releases/download/v8.3.0/yolo11n.pt`；`models/hand_landmarker.task`来自Google官方模型库`https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task`。Ultralytics适用其AGPL-3.0／商业许可；MediaPipe代码及模型发布条款应在生产分发前按上游许可证核对。下载由开发阶段完成，检测接口不自动下载资源。

本机已安装并验证MediaPipe 1.0.1。Docker需重新构建API和Worker镜像，仍需要目标服务器验证依赖安装与GPU容量。测试算法当前接入实时功能，离线灯具任务保持原有配置链。
