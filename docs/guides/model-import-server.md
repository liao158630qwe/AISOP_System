# 服务器模型导入（2026-11-05）

默认从当前浏览器电脑上传可信 Ultralytics `.pt` 权重。浏览器本地路径不能由服务器读取，选择文件后会实际传输字节。模型说明随上传保存，服务器读取任务类型和类别，生成 SHA256，保存独立版本。成功页可进入模型库、创建检测任务，或选择模型继续训练。导入模型不会自动发布现场任务。

## 存储与路径

- 浏览器上传无需操作服务器磁盘。管理员通过 SFTP 等方式预放文件时，推荐写入 `DATA_DIR/model-imports/`；页面中的 `inbox/…` 是该目录的相对标识。也支持项目 `models/`、`outputs/` 的既有训练产物。路径解析后必须仍位于允许目录内。
- 导入副本位于 `DATA_DIR/registered-models/`，原文件不删除。备份数据库时同时备份此目录。
- API 与 Worker 必须共享同一数据库及同路径的 `DATA_DIR`。Compose 已将 `analysis-data` 同时挂载为 `/data`，项目 `models` 挂载为 `/app/models:ro`。若使用宿主机目录放置导入文件，可将它绑定到 API 的 `/data/model-imports:ro`；需要直接用该目录中的权重训练时，Worker 也需要同路径挂载。
- 已入库权重通过 `model://模型ID` 进入训练页，后端检查归属、类型和散列，冻结实际文件路径。检测、旋转框和图像分类可用于后台训练；分割和姿态仍使用原 CLI。训练复用不依赖浏览器电脑的原文件。

## 大小、超时与重试

- `MAX_UPLOAD_BYTES` 控制 API 单文件上限，默认 524288000 字节（500 MiB）；修改时同步调整 Nginx `client_max_body_size`。候选接口返回当前限制，前端在上传前检查扩展名、空文件及大小；服务端仍对流式内容计数。
- 模型导入专用代理位置设置 600 秒读取/发送空闲超时、120 秒请求体空闲超时；浏览器上传/导入请求整体最多等待 600 秒。这些是不同计时方式，并不代表后台任务完成时限。更外层网关若有限制，也要单独配置。
- 上传以传输、服务器验证和入库完成三个阶段展示。传输达到 100% 只表示字节发送完成，尚未确认模型可用。格式/版本错误、网关 413/504 和网络中断分别提示处理方式。
- 两种导入接口接受可选 UUID `Idempotency-Key`。浏览器当前表单重试保留编号；同一编号的相同文件、名称、版本和说明返回同一模型，内容冲突返回 409。并发重试使用各自临时文件，仅保留成功登记的副本。
- `GET /api/v1/admin/model-imports/{key}` 查询当前账户已完成的结果。网络/网关异常后页面先查询，也可手动再次检查；404 表示尚无已完成结果，不能据此断言服务器没有在处理。
- 当前没有分片续传。传输未完成需重传；关闭/刷新页面不承诺后台继续上传。已完成的模型可在模型库查找。浏览器表单的请求编号不跨刷新保存。
- 模型说明通过 UTF-8 Base64 的 `X-Model-Notes` 请求头发送，避免长中文说明造成查询 URL 过长；后端仍兼容旧的 notes 查询参数。

## 验证

`npm run test:model-import-ui` 使用真实页面及模拟 API 检查来源切换、大小限制、网关错误、网络恢复、重复请求、说明、成功入口、移动端及退出竞态。

`npm run test:management-ui` 启动隔离数据库、API 和 Worker，使用真实权重验证服务器文件导入、浏览器上传、模型入库、训练页预选、场景发布、真实视频和摄像头推理。不会向正式模型库写入测试数据。

后端测试覆盖失败临时文件清理、流式超限、并发幂等、模型归属、文件散列、类型及目录边界。本机测试使用 SQLite；本次未在实际 Linux/Nginx/PostgreSQL 服务器上部署验收。
