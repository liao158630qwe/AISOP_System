# 六工位业务流程优化记录

日期：2026-11-06。延续六工位固定设备接入和集中推理，实现工件关联、检测结束归档、中断追踪和管理员配置反馈。部署与接口使用见 [六工位接入指南](../guides/six-station-realtime.md)。

## 业务行为

- USB 终端按产品名称、工件编号选择本工位当前工件，无需输入 UUID。默认“仅观察”，由操作员明确选择关联；工件更换后保留原选择并要求重新核对，不自动切换或降为观察。服务器在开流、推理和归档阶段验证工件仍未结束。
- “结束并归档”停止采样、等待在途请求，将最终算法结果保存到 SQL，再释放采集流。提交失败后保留同一轮供重试，冻结结果并阻止追加采样；归档重试不重复结束算法，也不把数据库等待时间计入采样缺口。完成记录支持跨 API 重启幂等查询。
- “停止采集”保存所选原因，未归档轮次记为中断。过期或被替换的未完成流在查询、重开或配置更新时持久记为中断；不能将最后一帧 PASS 补记成最终通过。归档成功后的释放重试不会覆盖已有结果。
- 终端展示本工位最近 20 轮，分别标记检测中、已归档、中断待复核，保留工件快照、相机、工位机、绑定版本、流代次、模型版本、时间及结果。接口支持工件筛选与分页，终端凭据不能读取其他工位记录。
- 管理页选择已发布且可用的场景，展示未登记、停用、人工检查、离线、结果过期、帧率不足和采样缺口等原因。刷新和工位切换保留配置草稿，显式重新载入才丢弃当前草稿。
- 无变化保存保留凭据和版本；实际修改配置或单独点击重新签发才轮换凭据。有有效采集流时拒绝变更或重签。凭据显示所属工位，可复制，退出登录后立即清除。
- 停止采集立即清除实时判定和指标，缩小空预览区；人工检查工位直接显示人工流程入口。桌面和 390px 窄屏布局已检查。

新增 `station_inspections` 表及历史、周期、工位活动状态查询索引，属于增量初始化；活动状态索引避免租约核对随着归档记录增长扫描整张表。既有未持久化的历史结果不能补建。人工工件的推进、结束、放行仍由既有人工流程执行，算法归档不会自动改变人工结果。

## 交付范围

本轮没有调整 GPU 并发默认值，也没有重新运行 GPU 性能实验。之前六路混合任务压测尚未整体达到逐路目标，仍以 [原性能记录](six-station-realtime-2026-11-06.md) 为准。

网络相机终端可查看当前工件、采样预览和历史；常驻采集器没有新增远程节拍控制。其正常退出或故障退出不会自动提交工件最终判定。若需按工件结束网络采集，应协调生产者停止送帧后调用归档与释放接口。原始 60fps 连续录像、完整媒体网关和六工位全工艺算法不在本轮交付中。
