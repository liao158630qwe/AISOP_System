# 整体审查与可靠性优化（2026-11-08）

本轮基于当前工作区检查接口、上传、会话、检测采样、人工复核与既有性能记录，修复有代码证据和故障回归的问题。改动集中在上传并发响应、浏览器请求错误处理、人工确认恢复及无效媒体拦截。

工作区原有大量未提交修改，未重置、提交或覆盖其余工作。验证使用独立 HTTP 服务、临时 SQLite 和浏览器配置；未重启正式服务、修改业务数据、模型、判定阈值或工位绑定。

## 本轮完成

| 项目 | 原问题 | 修改后的行为 |
| --- | --- | --- |
| 上传并发响应 | 普通视频探测已经在线程池执行，但文件发布后的数据库写入及提交失败核对仍在异步路由中同步执行；慢 SQL 会阻塞 API 事件循环 | 文件发布、完整事务和回执核对在同一工作线程完成；取消 HTTP 请求后仍由该线程负责文件生命周期，避免提交中的媒体被请求清理逻辑删除 |
| 网关错误 | 请求层假设所有响应均为 JSON，HTML/空响应会丢失 HTTP 状态码及 Retry-After | 保留 401/403/413/429/502/503/504 等状态和重试信息，返回可读提示；JSON 与上传统一处理；非法 Retry-After 归零，204 正常返回 null |
| 请求配置 | 展开 Headers 对象会丢失其中的头字段 | 用 Headers 合并请求头，并以当前会话覆盖 CSRF；验证请求取消信号不会取消请求自身的超时保护 |
| 人工确认恢复 | 临时登录过期或 CSRF 更新被归类为永久阻断，原确认无法自动恢复 | 保留请求编号、结论和原确认身份，等待登录恢复；重试仍先查询服务器记录，身份变化、权限错误、结果冲突继续停止提交 |
| 确认队列性能 | 每五秒读取全部本地确认记录，已完成记录及结果明细也参与反序列化；工位队列再次全量读取 | 本地库从 v1 升级到 v2，增加状态和重试时间索引；自动核对每批最多处理 25 条到期记录，工位列表只读取未完成状态；原记录和不可变请求保留 |
| 无效媒体 | loadeddata 事件被直接当作视频就绪，零尺寸或不支持的编码可能进入 Canvas 采样 | 检查真实解码宽高；无效视频提示使用浏览器支持的 H.264 MP4/WebM；启动与采样再次检查，阻止创建无画面的轮次 |
| 媒体生命周期 | 文件加载没有超时，切换素材可能留下旧监听器；相机播放失败后轨道可能仍被占用 | 文件加载 30 秒超时；切换素材主动取消旧加载并移除监听器、计时器；失败释放对象 URL，相机播放失败释放轨道；支持的视频/图片可继续正常使用 |

## 仍有不足，按优先级推进

1. **六路检测容量未达标。** [2026-11-08 六路螺丝实测](six-screw-terminal-performance-2026-11-08.md)中，三路推理并发服务六个页面，每路约 3.59–3.69 fps；提高到六并发约 2.98–3.57 fps，均未达到每路 10 fps。这是已有本机 RTX5070 Ti 的短时记录，本轮没有新增 GPU 吞吐测量。下一步应剖析螺丝模型内部执行和同步，基于实际六模型评估合批、缓存和执行并发，并在目标 RTX4090 与真实采集端复测。
2. **现场精度证据不足。** 既有贴条开发视频记录存在 R01/R05 动作漏观察；吞吐改善没有解决独立现场验证。需要完整工件/批次隔离的数据，覆盖漏装、错序、遮挡、机位偏移及光照，报告逐位置召回、误放行和工件级结果。本轮没有训练或调整阈值。
3. **部署更新与停止仍需验证。** 当前 Nginx 上游仍是固定 `api:8000` 配置；API 容器未声明停止宽限期，Worker 主循环未注册停止信号处理。应完善容器地址更新、停止接单、收尾预算和中断恢复，并实际执行重建/停止验收。本机未运行 Docker 部署测试。
4. **服务就绪与推理就绪仍混在一起。** 当前 `/ready` 看数据库和 Worker 心跳，不能说明已启用工位的模型可推理。需要独立维护各任务准备状态、失败原因和冷启动记录，并保留管理页在推理不可用时的可访问性。
5. **长期维护成本较高。** `station-detection.js`、`screw-dashboard.js` 和 `backend/app.py` 均超过千行，媒体、检测状态、展示、归档和恢复耦合较多。建议以已有浏览器契约为保护，逐次抽出媒体输入、确认队列界面、检测生命周期及独立 API 路由；每次只移动一个职责，避免同时改变业务语义。

更完整的部署风险见[服务器部署审查](server-deployment-audit-2026-11-08.md)，其中登录事务与代理来源已有后续修复，本轮进一步修复普通视频上传事务；该历史报告不是所有条目仍未处理的清单。

## 生效与限制

前端由服务读取当前文件并生成资源版本，刷新页面即可加载；打开旧版页面时建议统一刷新，以完成本地确认库升级。后台上传代码需要下次正常重启 API 生效，本轮没有打断正在运行的服务。旧版已被标记为 blocked 的确认继续保留人工核对语义，没有按错误文案推断并自动解锁。

本轮产物和执行前文件快照位于 `test-results/overall-review-20261108/`。浏览器异常媒体及采样测试使用受控夹具，不能证明所有 HEVC 文件都不受支持，也不能换算为现场识别精度、六机吞吐或长时间稳定性验收。
