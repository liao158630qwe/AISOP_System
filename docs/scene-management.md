# 模型与场景任务管理

后台入口：`http://127.0.0.1:8000/admin`（也支持 `/admin.html`）。首页右上角提供“模型与任务管理”入口，后台与检测首页共用登录会话。本机账户配置位于 `.runtime/local-settings.json`。

## 配置一个新场景

1. 打开后台的“模型库”，点击“导入模型”。可从项目 `models/` 中的 `.pt`、`outputs/` 下的 `best.pt` 或模型卡引用的产物选择，也可直接上传文件。
2. 填写模型名称与版本。系统读取模型任务类型和训练类别，并保存独立的权重副本与 SHA-256 校验值。后续训练覆盖原文件不会改变这个已注册版本。
3. 点击“创建任务”，填写场景名称、说明和关联模型。
4. 添加规则，选择类别、判定方式、置信阈值和数量。每条规则可以配置独立的归一化区域，也可选择参考图后点击“图上框选”。参考图仅在浏览器内用于标定，不上传服务器。
5. 调整输入尺寸、设备、采样率、连续确认帧数及最低清晰度。选择“保存草稿”可继续编辑；选择“发布到检测工作台”后，任务进入首页下拉列表。
6. 从首页选择已发布任务，或在后台点击“进入检测”，上传视频或开启摄像头。

例如，一个包装模型包含 `product`、`label` 和 `damage` 类别时，可以设置：整幅画面至少检出一个产品；标签区域至少检出一个标签；产品区域禁止出现损坏类别。不同工位可以复制任务，再调整区域、阈值和关联模型。

## 模型与规则边界

- 当前后台接入 Ultralytics `.pt` 检测、实例分割、关键点、旋转框、图像分类模型。特征分类 `.joblib`、任意框架权重和通用动作顺序模型不属于这个运行适配器。
- 每个场景关联一个模型，最多 32 条规则。分类模型每个区域输出一个类别，数量为 1；检测模型可以配置数量范围。
- 区域坐标是 `[x1, y1, x2, y2]`，取值 0–1。推理使用区域裁切，结果映射回整幅画面；更换相机位置后需重新标定。
- “必须检出”：达到最低数量且不超过最高数量，连续证据确认后通过。数量不足、遮挡、模糊或区域像素不足保持“待复核”。
- “禁止出现”：任意一个达到阈值的禁用目标经连续确认后判异常。未检出禁用目标只表示当前无该类证据；发布任务仍须至少一条“必须检出”规则。
- 模型类别来自训练结果，后台不能凭新增文字让模型识别新类别。更换新类别需导入对应训练权重。
- 结果仅反映所配置的视觉规则，不能替代安装扭矩、胶粘强度或完整工艺顺序验证。

## 检测、历史和版本

视频提交进入现有 Worker 队列，支持进度查询、取消、回放、采样目标、逐项规则与 HTML 报告。实际采样率取任务设置和视频帧率的较小值。历史按场景隔离；重新打开历史会使用该记录的模型、规则与版本。

编辑场景会递增任务版本，不会修改已经提交的视频任务。编辑冲突会提示刷新，防止覆盖另一窗口的修改。停用模型后，关联场景不能接受新检测；已提交视频仍使用其快照。

摄像头使用浏览器视频流，将采样 JPEG 交给真实模型推理；每轮隔离证据、时间戳和模型配置。后台改动任务或停用模型后，该摄像头轮次会停止并提示重新开始。结果过期后清除检测框与旧判定；退出或会话失效后停止摄像头。摄像头轮次仅保留当前会话结果，不写入视频历史。

浏览器摄像头需要本机地址或 HTTPS。若指定 CUDA 但服务器没有可用 GPU，会明确报错；可在任务中改为 CPU 或自动选择。

## 启动与验证

已有本机服务可双击项目“启动本机服务.cmd”重启。命令行执行 `npm run dev:local` 可在端口空闲时启动 API 和 Worker。已有数据库通过 `backend.init_db` 增加模型库与场景表，保留原任务和媒体记录。注册权重位于 `DATA_DIR/registered-models/`，备份时应连同数据库一起保存；API 与 Worker 必须能读取相同的数据目录路径。

Docker API 镜像已包含新增页面资源；更新部署时重建 API 和 Worker 镜像并执行数据库初始化。

```powershell
npm run test:management
npm run test:management-ui
```

接口与算法测试覆盖权限、发布校验、版本快照、模型停用、五类模型输出、证据确认、流隔离、模型上传失败清理和低帧率视频产物。

浏览器测试会启动独立数据库、API 和 Worker，使用项目真实螺丝模型及参考图验证：模型导入和上传、框选区域、草稿发布、启停模型、首页选择、真实视频分析、回放、历史版本、报告、手机布局和摄像头接口。摄像头输入是浏览器模拟视频源。测试进程结束后关闭，记录与截图保存在 `.runtime/scene-browser-*/`，不向日常模型库写入测试任务。该测试依赖本机 Edge 与 Playwright。
